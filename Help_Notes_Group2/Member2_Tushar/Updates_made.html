Implementation Complete

This document details the Express.js REST API endpoints developed by Member 2 to bridge the Next.js Frontend (Member 3) with the Joint Ownership smart contract functions (Member 1).

1. Summary of Work Done

The following components were implemented seamlessly without breaking existing single-owner routes:

  • ✅ Created fabric-api/src/jointOwnershipRoutes.js: Encapsulated all new joint ownership logic into a dedicated router module.
  • ✅ Added 6 REST API Endpoints: Handled the request parsing, business validation (like 100% share checks), and invoking Fabric SDK via fabricClient.js.
  • ✅ Org Validation: Hardcoded Collector Dispute Resolution endpoints to explicitly map to Org3MSP.
  • ✅ Registered Routes: Safely mounted app.use('/api/land', jointOwnershipRoutes) in fabric-api/index.js.

2. API Endpoint Reference for Member 3

Method Endpoint Chaincode Target Payload Description
POST /api/land/joint createApplication { applicationId, owners: [{ ownerId, sharePercent, ... }], primaryOwner }
POST /api/land/:id/consent addCoOwnerConsent { ownerId, remarks, username }
POST /api/land/:id/transfer-share transferOwnershipShare { fromOwnerId, toOwnerId, sharePercent, newOwnerData, username }
POST /api/land/:id/dispute raiseOwnershipDispute { raisedBy, reason, username }
PUT /api/land/:id/dispute/resolve resolveOwnershipDispute { decision, action, orderNumber, updatedOwners, username }
*Enforced to use Org3 Collector credentials internally.
GET /api/land/:id/owners getOwnershipDetails Returns the complete consent map and share breakdown.

3. Key Implementation Highlights

Validation Layer Example: 100% share validation logic inside the /joint route.

fabric-api/src/jointOwnershipRoutes.js
const totalShare = owners.reduce((s, o) => s + parseFloat(o.sharePercent || 0), 0);
if (Math.abs(totalShare - 100) > 0.01) {
    return res.status(400).json({ error: `Shares must total 100%. Got: ${totalShare}%` });
}

Fabric SDK Invocation Example: Safe abstraction using the pre-existing fabricClient class.

fabric-api/src/jointOwnershipRoutes.js
const caller = username || 'admin-registration';
await fabricClient.connect(caller);
    
const response = await fabricClient.submitTransaction(
    caller,
