Prerequisites (Ye Software Install Hone Chahiye)

Project start karne se pehle ensure karo ki aapke computer me ye 4 tools properly installed hain:

🟢 1. Node.js & NPM

Recommended: Node.js v18 LTS ya v20 LTS.

Terminal 
node -v
npm -v
🐳 2. Docker Desktop (Windows)

Docker Desktop running hona chahiye with WSL 2 backend enabled.

PowerShell / WSL 
docker --version
docker ps
🐧 3. WSL 2 (Ubuntu) ya Git Bash

Hyperledger Fabric ke bash scripts (.sh) run karne ke liye Linux terminal zaroori hai.

PowerShell (Install WSL if missing) 
wsl --install
🍃 4. MongoDB Database

Ya to MongoDB Atlas (Cloud URI) use karo ya Local MongoDB service (port 27017).

Atlas Connection URI Format 
mongodb+srv://<user>:<pass>@cluster0.xxx.mongodb.net/elandrecords?retryWrites=true&w=majority

Secret Keys (.env) Setup (Important ⚠️)

Security ke liye .env.local Git me commit nahi hota. Repo me client/.env.example di gayi hai. Aapko isko copy karke apni .env.local banani hai:

🚫
WARNING: Kabhi bhi .env.local ko GitHub par push mat karna!
Isme aapka MongoDB password, Pinata API key aur Gmail App password hota hai. Ye hamesha local PC par hi rahega.
Command: Copy Template to .env.local
Client folder me jaakar example file ko copy karein:
Terminal 
cd client
cp .env.example .env.local
Kon-Kon si Keys Setup Karni Hain?
Ab client/.env.local file ko kholo aur ye keys enter karo:
Variable Name Kya Value Daalni Hai? Kahan Se Milega?
MONGODB_URI Aapka MongoDB connection string (DB name: elandrecords) MongoDB Atlas dashboard se Cluster Connect string lein.
NEXT_PUBLIC_FABRIC_API_URL http://localhost:3001 Same rehne dein (Hyperledger REST API bridge).
NEXT_PUBLIC_BASE_URL http://localhost:3000 Same rehne dein (Next.js frontend).
PINATA_API_KEY
PINATA_SECRET_KEY
PINATA_JWT		 Pinata Cloud IPFS Keys (Property documents store karne ke liye) pinata.cloud par free account banayein aur API keys generate karein. (Agar blank chodenge to mock hashes use honge).
SMTP_USER
SMTP_PASSWORD		 Gmail ID & 16-character App Password (OTP email ke liye) Google Account → Security → 2-Step Verification ON → App Passwords generate karein. (Development me OTP console me bhi print hota hai).

One-Time (First Time Only) Setup Files

Ye files sirf ek baar (pehle din) run karni hain taaki database me Admin aur Officials create ho jayein aur Blockchain network initialise ho jaye:

🌱 Step A: Database me Users & Officials Seed Karna

In scripts ko run karne se MongoDB ke andar default Super Admin aur government officials (Clerk, MRO, Surveyor, Collector) insert ho jayenge:

Client Folder me Terminal 
cd client

# 1. Super Admin banayein (admin@elandrecords.gov / admin123)
node create-admin.js

# 2. Saare Officials banayein (Clerk, Surveyor, MRO, Collector)
node create-officials.js
✅
Dono script complete hone par "Connected to MongoDB" aur "Done!" ka message dikhega.
⛓️ Step B: Hyperledger Fabric Network Initialize Karna

Ye script Docker containers banayegi, mychannel create karegi, 3 organizations ko join karegi aur Smart Contract deploy karegi:

WSL 2 (Ubuntu) / Git Bash - Root Folder 
# Project root folder me jayein
cd /c/Users/hmury/Desktop/LandRecords_PBL/LandRecords_extracted

# Setup network script ko executable permission dein
chmod +x setup-network.sh *.sh

# Network setup run karein (Takes 2-4 minutes)
./setup-network.sh
ℹ️
Note: ./setup-network.sh sirf pehli baar chalana hai. Roz roz isko run nahi karna hai!

Roz Project Kaise Start Karein (Daily Running)

Project ke total 3 components run hote hain: 1. Hyperledger Docker Network, 2. Fabric API (Port 3001), aur 3. Next.js Client Frontend (Port 3000).

🌟 Method 1: 3-Terminal Setup (Recommended for Development & Debugging)
Best for Developers

Is method me fabric-api apne alag terminal me chalti hai jisse aap live API calls, JSON responses, errors aur smart contract execution logs direct screen par dekh sakte hain:

🟢 Terminal 1: Fabric Network

Docker containers ko resume/start karta hai:

WSL 2 / Root Dir 
./start-network.sh
Peers, Orderer & CouchDB live ho jayenge.
🔵 Terminal 2: Fabric REST API

Blockchain REST bridge on Port 3001:

fabric-api/ folder 
cd fabric-api
npm start
Live server running at http://localhost:3001
🟣 Terminal 3: Client Frontend

Next.js web portal on Port 3000:

client/ folder 
cd client
npm run dev
Browser: http://localhost:3000

Project & Network Ko Stop Kaise Karein

Kaam khatam hone ke baad RAM aur CPU free karne ke liye 2 options hain:

🟢 Option 1: Clean Stop (Data Safe / Recommended)

Isse ledger aur MongoDB data safe rehta hai, sirf containers aur servers pause ho jaate hain:

PowerShell me 
.\stop-network.ps1
WSL / Git Bash me 
./stop-network.sh
🔴 Option 2: Full Network Reset (Wipe)

⚠️ Warning: Is command se saara blockchain data, crypto certificates aur channel destroy ho jayega:

WSL / Git Bash me 
cd fabric-samples/test-network
./network.sh down
Sirf tab use karein jab scratch se naya network shuru karna ho!
